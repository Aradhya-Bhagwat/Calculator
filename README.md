# 🧮 Simple Calculator

A clean, simple calculator built with **HTML, CSS, and JavaScript**. Perfect for beginners learning to build your first web project.

---

## ✨ What Makes It Great

### 🎯 Core Features
- **Four Essential Operations:** Add, subtract, multiply, and divide with ease
- **Instant Calculations:** Get your answer the moment you press the equals button
- **Smart Controls:** Clear everything with `AC` or fix mistakes with the `DEL` button
- **Clean Interface:** A beautifully designed layout that's easy on the eyes
- **Works Everywhere:** Fully responsive design that adapts to any screen size—phone, tablet, or desktop

### 💡 Why You'll Love It
No distractions. No unnecessary features. Just a calculator that works exactly how you expect it to.

---

## 🚀 Getting Started

Getting this calculator up and running is incredibly simple:

### 1. Download or Clone
Clone the repository or download the files to your computer:
```bash
git clone https://github.com/yourusername/Calculator.git
cd Calculator
```

### 2. Open in Your Browser
Simply open the `index.html` file in your favorite web browser. That's it! No installation needed.

### 3. Start Calculating
- Click number buttons to enter values
- Choose an operation (`+`, `-`, `×`, `÷`)
- Press `=` to see your result
- Use `AC` to start over or `DEL` to remove the last digit
